# 근현대전 파노라마

> 270° 파노라마를 활용한 근현대 역사 교육용 웹 프로그램

## 소개

**근현대전 파노라마**는 270° 파노라마 사진과 인터랙티브한 지도를 활용하여 사용자가 역사적 장소를 직접 탐색할 수 있도록 제작한 교육용 웹 프로그램입니다.

학교 태블릿, 스마트폰, PC 등 다양한 기기에서 웹 브라우저를 통해 사용할 수 있도록 제작했습니다.

## 주요 기능

- **장소 선택 지도** — 지도에서 원하는 장소를 선택하여 탐색
- **270° 파노라마 뷰어** — Three.js 기반의 3D 파노라마 뷰어
- **장소별 정보 제공** — 장소마다 다른 제목, 설명, 대표 이미지 제공
- **자세히 알아보기** — 장소별로 서로 다른 외부 정보 링크 연결
- **화면 이동** — 정보 패널 열기 및 지도 화면으로 돌아가기
- **반응형 화면** — PC, 태블릿, 스마트폰 등 다양한 화면 크기 대응

## 사용 기술

- HTML5
- CSS3
- JavaScript
- Three.js `r180`

## 실행 방법

### 1. 프로젝트 다운로드

GitHub에서 프로젝트를 다운로드합니다.

### 2. 로컬 서버 실행

VS Code의 Live Server와 같은 웹 서버를 이용하여 `index.html`을 실행합니다.

```text
http://localhost:5500
```

### 3. 다른 기기에서 접속

같은 네트워크에 연결된 태블릿이나 스마트폰에서는 PC의 로컬 IP 주소와 포트를 이용하여 접속할 수 있습니다.

```text
http://PC의_IP주소:5500
```

## 사용 방법

1. 시작 화면에서 지도를 확인합니다.
2. 지도에 표시된 장소 핀을 선택합니다.
3. 해당 장소의 270° 파노라마가 표시됩니다.
4. 화면을 드래그하거나 터치하여 주변을 탐색합니다.
5. `ⓘ 정보` 버튼을 눌러 장소 정보를 확인합니다.
6. `자세히 알아보기`를 통해 추가 정보를 확인합니다.
7. `← 돌아가기`를 눌러 장소 선택 화면으로 돌아갑니다.

## 제작 목적

역사적 장소를 단순한 사진이나 글로 학습하는 것에서 벗어나, 270° 파노라마 콘텐츠를 통해 학습자가 직접 주변을 탐색하는 방식의 교육 경험을 제공하는 것을 목표로 합니다.

또한 학교 태블릿과 같은 교육 환경에서 별도의 프로그램 설치 없이 웹 브라우저만으로 사용할 수 있도록 제작했습니다.

본 프로젝트는 교육 목적으로 제작된 웹 프로그램입니다.
